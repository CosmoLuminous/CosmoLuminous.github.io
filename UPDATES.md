# Website Updates - Profile & Cover Photo Integration

## Changes Made

### 1. HTML Structure (index.html)
- Added `hero-cover` div for background cover photo
- Added `hero-profile-wrapper` with profile image
- Profile image displays as a circular photo with border and shadow effects

### 2. CSS Styling (css/style.css)
- **Hero Section Redesign:**
  - Cover photo as full-width background with overlay
  - Profile picture (180px) centered with circular border
  - Improved text shadows for better readability over cover photo
  - Enhanced button styling with backdrop blur effect
  
- **Responsive Design:**

  - Maintains visual hierarchy across all devices

### 3. Visual Enhancements
- Cover photo with gradient overlay (blue tones matching brand)
- Profile image with hover effect (scale + shadow)
- Better contrast and readability
- Professional LinkedIn-style presentation
